这是一个基于 Hugo 的主题版本，延续了原始 Tufted 模板偏爱的宽边栏、衬线字体和内容优先排版。

{{< marginnote >}}
![一对凤头潜鸭](/images/tufted-duck-female-with-duckling.webp)

凤头潜鸭是这个模板的视觉灵感之一，也是原项目名字的来源。
{{< /marginnote >}}

你可以把它用于博客、文档页、作品集或简历站点。首页内容照常用 Markdown 写，博客列表、单篇文章和页脚导航由主题负责渲染。

{{< figure src="/images/devices.webp" alt="主题预览" caption="示例站点在多设备上的预览效果。" >}}

主题附带了：

- 深浅色模式切换
- 文章列表按年份归档
- 代码块行号与复制按钮
- 边栏注释与移动端折叠
- 一个可直接运行的 `exampleSite`

想继续看结构，可以去 `Docs`；想看文章样式，可以去 `Blog`。
